# 機器翻譯盲測評分表（繁體中文）

這份表格用來比較兩個看不到名稱的翻譯版本。請依照每一列的中文原文，分別閱讀 `output_1` 和 `output_2`；不要猜測或尋找模型名稱，也不要讓某一項分數影響其他項目。

## 填寫方式

1. 在 `output_1_fidelity`、`output_1_fluency`、`output_1_terminology` 欄位，分別為版本 1 的三個面向填入 **1 到 5 的整數**。
2. 在 `output_2_...` 欄位，以相同方式評分版本 2。
3. 在 `preferred` 欄填 `1`、`2` 或 `tie`，表示整體上偏好版本 1、版本 2，或兩者相當。這是整體偏好，不是三項分數的加總。
4. 如有值得說明的譯法、錯誤或術語問題，請寫在 `comment`。若沒有，可留白。
5. 請保留 `id`、原文和兩個譯文不變。用試算表軟體另存 CSV 時，請保持欄位名稱與順序。

| 分數 | 一般意義 |
|---:|---|
| 5 | 很好：準確、自然或用語恰當，幾乎沒有問題 |
| 4 | 良好：大致符合要求，只有輕微問題 |
| 3 | 尚可：意思或表達可理解，但有明顯可改進之處 |
| 2 | 不佳：有重要錯誤或不自然之處 |
| 1 | 很差：嚴重錯譯、難以理解或用語錯誤 |

## 三個面向請分開判斷

- **忠實（fidelity）**：譯文是否保留中文原文的意思、細節、語氣及句間關係？是否有遺漏、增添或誤解？
- **流暢（fluency）**：日文是否自然、通順且符合一般日語表達？即使內容正確，不自然或難讀也應降低此項分數。
- **術語（terminology）**：佛教概念、人名、典籍名與修行用語是否使用正確且一致的日文說法？請特別留意佛教術語，不要只因句子流暢就給高分。

每一面向各自評分：例如，譯文可以忠實但不流暢，也可以很流暢但把佛教術語譯錯。若不確定某個術語，請依上下文判斷並在 `comment` 註明疑問；不要為了猜測而把三項分數合併。

## 評分檔與隱藏對照表

`make` 會產生供評分者使用的 CSV，以及另一個包含模型名稱與左右位置對照的 `*.key.json`。請只把 CSV 給評分者；不要傳送、開啟或分享 key 檔。完成後保留原始 CSV 格式，交回評分表供彙整。

範例指令：

```text
python tools/mt_eval_sheet.py make --src sentences.tsv --a outputs_a.jsonl --b outputs_b.jsonl --out sheet.csv --seed 42
python tools/mt_eval_sheet.py score --sheet filled.csv --key sheet.key.json
```

每份輸入 TSV 需有標題列 `id` 和 `source_zh`，並包含 20 筆句子。兩個 JSONL 檔每行需包含 `id` 及 `translation`。若有多位評分者，可重複 `--sheet` 參數；工具會一併彙整分數，並按共同評分題目計算各評分者偏好欄的一致百分比。
