# 禪譯 Zen Bridge 使用手冊（主持端）

這份文件是給大學禪學社、社課主持人、幹部與值班人員的實際操作說明，重點放在「主持端如何啟動、控制現場字幕、讓觀眾掃 QR 看字幕、以及事後整理與匯出」。

這份文件依照目前倉庫裡的實際行為整理，並以本機執行為主，不假設任何額外工程能力。

## 1. 先說結論：這個系統是怎麼跑的

- 主持端在本機電腦執行；聽眾端用手機、平板或其他同一 Wi‑Fi 裡的裝置連到房間頁面。
- 服務本身是本地服務，不依賴雲端儲存來顯示即時字幕。
- 目前即時翻譯提供英文；日文為「規劃中，尚未接入即時管線」。系統設計為每個場次只使用一種目標語言，不會同時混用多種翻譯目標。
- 主持端可以暫時「私密暫停」音訊，讓現場不出現在觀眾端的內容被丟棄；恢復後再繼續。
- 一個房間可以維持一組詞彙表，幫助譯文更穩定；若有欄位被鎖定，該詞不能直接覆蓋。
- 管理後台可以在本機做事後修正、審稿、匯出字幕與 SRT/VTT。
- 目前的預設策略是：本機保存文字；不向外傳送錄音；重要場次請在結束後立刻匯出；長期保留並非預設狀態。

## 2. 啟動 App

### 2.1 直接啟動

在 Windows 環境中，通常使用桌面捷徑或 `start.bat` 啟動。程式讀取本機的 `.env` 與設定，主機頁面通常會在本機開啟：

- host（主持頁）：`http://127.0.0.1:8780`
- 房間觀眾頁：`http://<本機區網IP>:8780/r/<room_id>` 或透過 QR

在專案文件裡，啟動流程明確說明：

- `start.bat` 是一般啟動方式。
- 若要啟動後台管理界面，需另外開啟本機 admin 後台；詳見「管理後台」章節。
- 若有防火牆或區網限制，則可能沒有可分享的位址，這時 QR 不會正常產生。

### 2.2 首次使用與最小啟動檢查

首次啟動前，至少確認：

- 麥克風可用；
- 這台電腦能連到同一 Wi‑Fi；
- 這台電腦的防火牆允許私人網路存取；
- 如需部署本機 admin 後台，確認 127.0.0.1:8791 可用。

若啟動後看不到 QR 或聽眾連不上，請先確認共享位址與防火牆設定，並檢查「服務是否在私有網路上開啟」

## 3. 主持頁與觀眾頁是什麼

### 3.1 主持頁

主持頁會顯示：

- 房間名稱／room id
- 麥克風選擇
- 收音狀態
- 識別速度（RTF）與佇列狀態
- 目前字幕（中文、英文）
- QR code 與分享連結
- 詞彙表輸入框
- 匯出 SRT 按鈕
- 私密暫停／恢復

主持頁有明確的「開始聽」與「停止」操作。開始收音前，請先選好麥克風與房間。畫面上也會顯示「聽眾掃這裡」的 QR。

### 3.2 觀眾頁

觀眾用手機掃 QR 後，會進入 `/r/{room_id}` 的房間頁。這個頁面可依設定：

- 顯示中英雙語；
- 顯示中文或英文單一語言；
- 轉成投影模式；
- 根據螢幕亮度、字級與主題作個人調整。

觀眾頁會持續接收房間內的最新字幕，重連後會補回最近保留的內容。它不需要安裝 App，也不需要額外登入。

## 4. 每個場次只選一個目標語言

目前即時翻譯只提供英文；日文為「規劃中，尚未接入即時管線」，目前不能用於即時字幕。系統設計仍是「每個場次只能使用一個目標語言」，不會在同一場次混用多種翻譯目標。

目前直播輸出為英文。詞彙表可用來協助穩定英文譯文；日文目標尚未接入即時管線。

## 5. 私密暫停／恢復

主持頁有一個名為「私密暫停」的按鈕。作用是：

- 暫停當下的音訊捕捉與顯示；
- 這段期間收錄到的內容被視為「私密」而不會公開顯示；
- 恢復後再接續新字幕。

這個功能是用來處理非公開場景、私下檢討、臨時休息或不想讓聽眾看見的內容。

實際實作上，當房間處於暫停狀態時，主持端會看到一個啟發式狀態，例如：

- 私密暫停：麥克風已關閉
- 恢復後回到正常收音狀態

在暫停期間，不會讓已經收進來的內容流到觀眾端。

## 6. 詞彙表（glossary）怎麼用

主持頁的術語欄位是一個文字框。格式是：

- 一行一個詞條；
- 形式為：`標準詞=英文`；
- 別名可寫成：`標準詞|別名=英文`；
- 例如：`般若=prajna`、`禪學社|柴學社=Zen Club`

這個欄位是為了幫助 ASR／翻譯維持固定的術語。

實際限制：

- 一個房間一組詞彙表；
- 一次最多有一定數量的條目（目前程式有上限限制）；
- 若某個詞被鎖定，該行通常只能看不能直接重寫；
- 某些格式、註解、分類、過於複雜的內容不能直接用純文字框覆蓋。

如果你需要修改更完整、技術性較強的詞表，系統會明確提示：請找負責詞表的人，並使用 `PUT /api/rooms/<room_id>/glossary` 這個技術 API 方式更新。

## 7. 事後檢查與修正逐字稿

如果需要在事後做修正，請使用本機 admin 後台：

- 本機地址：`http://127.0.0.1:8791/admin`
- 這個管理頁面只在本機執行，不對外提供一般公開存取。

管理後台可提供：

- 所有場次列表與狀態；
- 逐段字幕審稿與修正；
- 中文／譯文切換編輯；
- 版本歷史；
- 詞彙表管理；
- 匯出工作；
- 角色與權限控制。

實際編輯器支援鍵盤操作，例如：

- `j` / `↓`：下一段
- `k` / `↑`：上一段
- `t`：切換中／譯文
- `Enter`：開始編輯
- `Ctrl + Enter`：儲存
- `Esc`：取消
- `Ctrl + Z`：回到上一版

如果有人剛修正過同一段，管理後台會提示「資料已被別人修改，請重新載入」；這是為了避免覆蓋別人的編輯。

## 8. 輸出 SRT / VTT / 匯出檔案

### 8.1 主持頁的快速匯出

主持頁有「匯出 SRT」按鈕，可直接產生該房間的字幕匯出檔。

### 8.2 管理後台的完整匯出

管理後台的「匯出」頁面支援：

- SRT
- VTT
- Markdown
- 可選內容：雙語、只中文、只譯文

匯出流程通常是：

1. 輸入場次 id；
2. 選擇格式與內容；
3. 建立匯出工作；
4. 等待任務完成；
5. 下載輸出檔案。

管理後台的匯出是本機生成，不需要額外雲端服務。

## 9. 隱私、資料儲存與保留時間

### 9.1 本機儲存，且不保存錄音

目前文件明確指出：

- 這套系統是本機運行；
- 文字資料可保存在本機 SQLite；
- 不保存錄音檔；
- 管理後台的資料與字幕都保持在本機資料庫；
- 服務本身不需要外部雲端儲存來顯示字幕。

根據目前設定，資料位置大致是：

- `data/captions.sqlite3`（若使用預設本機資料路徑）
- `.env` 中的 `BREEZE_DATA_PATH` 可調整資料位置

### 9.2 保留時間

實際文件顯示：

- 預設會保留 24 小時；
- 重要場次請在結束後盡快匯出；
- 如果沒有額外設定，請把保存期限當作短期保留，不當成永久歸檔；
- 若需要更長保留，可在 `.env` 設定 `BREEZE_CAPTION_TTL`（秒數）。

這裡要注意：有些版本／安裝方式的「是否啟用儲存」是可變的；如果你沒有明確啟用資料儲存，則只有近期字幕保留，不等於長期歸檔。（待確認）

### 9.3 隱私提醒

- 不要把 `.env` 或 API 金鑰放到公開倉庫或公開網頁；
- 文字與場次資料保存在本機，不要把它們放在 OneDrive 或網路磁碟（文件中已明示網路磁碟／WAL 不安全）；
- 若要備份，請用本機磁碟、外接硬碟／第二顆磁碟、或正式的備份流程；
- 容器與雲端部署情境需另行確認，請以本地主管理員設定為準。

## 10. 如果字幕卡住、拖延或跟不上

這是最常見的現場問題，處理方式如下：

1. 先看主持頁上的辨識速度（RTF）與狀態文字。
2. 如果顯示「處理積壓，已暫停產生新錄音」或機器判定隊列太長，請先停下說話，等字幕隊列清掉。
3. 維持安靜，讓系統先補回目前的處理。
4. 若狀況持續，請檢查：
   - 麥克風是否正常；
   - 電腦是否改用電池模式（ASR 可能變慢）；
   - 其他背景程式是否吃掉 CPU；
   - 已經有太多未處理段落。
5. 如果仍無法恢復，請關閉不必要程式，改用有線／較穩定的供電環境，或重啟主服務。

這個系統會明確提醒：不要把「處理積壓」當成正常即時服務；它表示目前無法維持低延遲。

## 11. 常用檢查清單

每次上課前可以做 5 秒檢查：

- 麥克風能否被選到；
- 主持頁是否顯示「收音狀態：聽講中」；
- QR 是否可掃；
- 觀眾端是否能看到字幕；
- 詞彙表是否已載入；
- 若有必要，先開管理後台確認最近資料。

## 12. 小提醒

- 本機服務可用 `BREEZE_PORT` 變更埠號；預設為 8780。
- 若 port 已被佔用，請停掉衝突程式或更換埠號。
- 目前即時翻譯的語言選項為英文；日文為「規劃中，尚未接入即時管線」。設計原則仍是每個場次只使用一種目標語言。
- 若你的版本的介面與本文有細微差異，請以實際執行畫面為主；文案是按目前倉庫實作整理。（待確認）

## 13. 看到這些狀態時怎麼判斷

- 「待命」：還沒開始收音。
- 「聽講中」：正常接收。
- 「私密暫停：麥克風已關閉」：已進入私密暫停。
- 「處理積壓，已暫停產生新錄音」：系統過載或延遲太高，請先停一下說話。
- 「辨識速度：開始聽之後才有數字」：剛開始還沒有足夠樣本，請等待兩段樣本累積。

如果你有更細部的需求，例如「怎麼做整場備份」、「目前支援的即時翻譯語言」或「怎麼讓觀眾看投影版」，請參閱 FAQ。
