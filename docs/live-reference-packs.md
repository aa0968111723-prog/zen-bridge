# 中英日即時翻譯參考

隨 App 提供 400 筆原創中英日字詞和常用句，共 800 組中英/中日對照。涵蓋課堂教學、研究討論、會議協作、日常溝通、字幕操作與身心覺察。原始檔為 `sidecar/live-room/app/resources/live_reference.tsv`，使用 UTF-8 與 CC0 原創文字授權。

參考包補充現有 CC-CEDICT/ECDICT，並未代替它們，也不是專業人工審定的翻譯記憶。多義詞仍需上下文判斷。

## 即時使用方式

每句在本機選出最多 8 筆相關參考，長語句優先，不同時重複塞入整句與其中的單詞。翻譯器仍由模型產生譯文，不直接替換字幕，不自動寫入 TM；使用者術語與已確認例句優先。

- 英文即時翻譯：參考以 JSON 資料放入提示。
- Hy-MT/Index 中日翻譯：使用日文欄位並標記為可選措辭參考。
- 桌面 Ollama/Hermes：支援 `zh-en`/`zh-ja`，路由選擇不变；本機模式不自動呼叫雲端。
- 桌面模型容量不足時先捨棄自動參考，再保留已確認的例句；當前句子完整保留且放在最後。支援主介面實際使用的 `currentUtterance` 欄位與舊 `text` 欄位。

`ZEN_REFERENCE_PACK_ENABLED=0` 可停用。代理狀態的 `reference_pack` 顯示啟用狀態、筆數、語言對數及每句上限，不包含錄音或字幕。

## 資料庫整理

WAL 自動回寫改為 256 頁一批，約 1 MiB（4 KiB 頁面），避免累積較大批次後同步整理。整理遇到讀取者占用時保留待處理狀態，下一筆提交後重試，不再把未完成整理視為已完成。寫入 busy_timeout=5000、synchronous=NORMAL、WAL 模式與資料遺失/1 秒效能檢查門檻維持。

永久不結束的外部讀取交易仍可能阻止 WAL 回收；程式不強制關閉外部工具或刪除 WAL。備份請沿用 App 的 SQLite 備份流程。
