# 主工作台字幕預覽

0.5.3 在 Zen 主工作台接入配對電腦的 SenseVoice 預覽。設定「即時草稿與停頓切句」後，下次收音每秒嘗試發送當前片段，不超過6.5秒／220KB的16kHz單聲道PCM16 WAV。

預覽、正式 ASR、文字翻譯分開處理。每個瀏覽器最多一份預覽在途，忙碌時丟棄預覽，不排隊拖慢正式字幕；gateway 預覽容量獨立為1，App預覽採單緒。主機配對時先暖模型，記憶體不足或載入失敗不阻止正式辨識。

灰字明確標示尚未定稿，不保存音檔、不寫入字幕或翻譯記憶、不產生譯文。只有既有 `/api/audio` 正式辨識流程才保存。開始新片段、暫停、停止或離開頁面會清空預覽，過期回應不能重新顯示；顯示預覽時隱藏上一句譯文，避免錯配。

`/api/preview` 只接受已配對主持App，先認證再讀取有界請求，核對課程及方向；後端Bearer權杖留在伺服器，透過既有配對WSS代理傳送。舊App無preview能力時停止預覽，保留原正式辨識。

實機公共音檔4秒：冷啟動4.06秒、暖模型後0.61秒（單緒），並非真人課堂端到端驗收。即時準確度及長時間課堂仍需原始錄音與人工對照。
