# 原音備份與翻譯恢復：第一批修正

開始收音前先確認 IndexedDB 可以建立錄音，再開啟麥克風。每約5秒將16kHz單聲道PCM WAV分段寫入；原音包含靜音、字幕處理暫停期間及短尾段。ASR／翻譯失敗不會停止麥克風。字幕仍採有界暫停，不以無限記憶體佇列隱藏處理速度不足。

主畫面「本機原音備份」可下载同一次收音已保存的 WAV。錄音與網站音檔欄位是不同來源，這批不補回歷史缺失的音檔，也不改動既有字幕或人工修訂。原音不上傳，但原本選用雲端ASR的辨識片段仍會依既有設定送出。

本機儲存寫入失敗、寫入等待超過4個片段、或單次錄音到512MiB時，明確提示並停止收音，先前已寫入部分仍可下載。異常關閉最多約5秒尚未提交；瀏覽器配額／清除網站資料／解除安裝可能移除備份，請下載另存。這不是作業系統級錄音，ScriptProcessor背景執行缺口仍需真人驗收。

桌面翻譯總預算55秒，包含agent翻譯lane排隊；混合模式local最多20秒，cloud只用剩餘時間，保留gateway60秒餘裕。取消仍等待既有推論緒結束後才釋放lane，避免重連產生重疊推論。本機與雲端單模式不默默切換服務。

metrics恢復最近100筆歷史，最多保留兩個有限JSONL檔。已保存統計只計成功寫入的保存視窗；寫入失敗計數在操作台顯示。載入舊大檔以有限記憶體讀取，再壓縮保存視窗，不把字幕／音訊／金鑰放進metrics。

## 驗證

- capture模擬：暫停前、暫停中、靜音與短尾段全部進原音備份；試音不保存。
- IndexedDB故障注入：重開讀取、WAV片段順序、先前寫入部分保留、儲存不可用、刪除。
- 實際瀏覽器：兩個生成的測試片段保存，重新載入後匯出2秒WAV、64044bytes、PCM順序正確；沒有開真人麥克風。
- 假時鐘：慢local→cloud剩餘預算、單模式不切換、預算耗盡不調用上游；agent排隊逾時不啟動模型。
- metrics：跨重啟、輪替、寫入失敗、敏感欄位排除、多緒記錄。

此批尚未修復主UI背景校正回寫、網站缺譯重翻、雲端音檔與字幕交易、講者辨識能力說明及整堂課真人收音。部署與安裝驗收另行記錄，不能把開發測試當成已更新正式App。
